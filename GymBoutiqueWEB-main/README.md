# IronStrong Fitness - GymBoutiqueWeb

Proyecto académico integrado desarrollado con **Next.js**, **Tailwind CSS** y **TypeScript**.

## Repositorio Público
- **GitHub**: https://github.com/Fa61anh/GymBoutiqueWeb

## Descripción del Proyecto
Aplicación web orientada a la gestión de gimnasios y boutique deportiva que incluye:
- **Módulo de Membresías**: Registro e inscripción de clientes a planes fitness.
- **Catálogo de Productos y Carrito**: Selección de productos, manejo de estado global con `useCarrito` y cálculo de totales.
- **Pruebas Unitarias y Cobertura**: Suite de pruebas con **Karma** y **Jasmine** para verificar componentes y hooks.
